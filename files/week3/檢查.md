# WEEK3 完成檢查

教師用這份清單核對學生是否照手冊做完。學生筆記要附畫面，每張都要看得到指定結果。只貼指令、沒有結果，不算完成。

兩個網站以學生自己的網域為準。手冊範例是 `https://q1.qqnice.org` 與 `https://k1.kknice.net`。帳號以學生自己的為準，不一定是 `azureuser`。

## 必交畫面

| 順序 | 畫面裡必須看得到 | 沒有這項就不算完成 |
|---|---|---|
| 1 | `./backup.sh` 跑完，最後一行是 `完成：/home/帳號/backups/日期時間` | 只有 `.partial-` 開頭的目錄，或沒有「完成：」 |
| 2 | `ls -l "$B"` | 正好 6 個檔，權限都是 `-rw-------`：`db-wordpress.sql`、`posts.tsv`、`wp-data.tar.gz`、`wp-files.sha256`、`config.tar.gz`、`SHA256SUMS` |
| 3 | 四個版本指令的輸出，加上 `docker compose images`、`docker compose ps` | 映像還有 `latest`、`lts` 或 `stable`；db 不是 `healthy` |
| 4 | `(cd "$B" && sha256sum -c SHA256SUMS)` | 不是五行都 `OK` |
| 5 | `tar tzf "$B/wp-data.tar.gz" \| grep -cx './wp-config.php'` | 不是印出 `1` |
| 6 | `docker compose down -v` 之後的 `docker volume ls` | 還看得到 `webstack_db-data` 或 `webstack_wp-data` |
| 7 | `./restore.sh` 的完整輸出 | 沒有同時出現「檔案比對一致」和「文章比對一致」 |
| 8 | 還原後的 WordPress 首頁 | 文章還在，而且文章裡的圖片打得開 |
| 9 | WordPress 後台已登入 | 停在安裝畫面 |
| 10 | 還原後的靜態網站 | 不是學生自己的首頁 |
| 11 | `sudo sshd -T` 那四行，以及強制密碼登入被拒絕 | 停損沒做 STEP 10 的人，改交「新視窗已能用金鑰登入」；不要收只有設定檔、沒有測試的畫面 |
| 12 | `sudo fail2ban-client status sshd` | 沒有 `Status for the jail: sshd` |

第 6 張和第 7 張要是同一份備份。還原用的目錄必須等於第 4、5 張檢查過的那個 `B`，不能用更早的另一份。

版本畫面要對得上 WEEK3 版 `compose.yml`：

| 服務 | 標籤 |
|---|---|
| db | `mariadb:12.3` |
| wordpress | `wordpress:7.1-php8.3-apache` |
| nginx | `nginx:1.30-alpine` |
| certbot | `certbot/certbot:v5.8.0` |

學生查到的版本和上表不同時，筆記要寫改了哪一行。資料庫不可以改成比目前更舊的版本。

`sshd -T` 預期值：

```text
permitrootlogin no
maxauthtries 3
passwordauthentication no
kbdinteractiveauthentication no
```

行的順序可以不同，值要一致。密碼測試應出現 `Permission denied (publickey).`

## 筆記要寫的內容

1. 紀錄表每一格都填實際值，不要留範例日期：
   - 第一次備份目錄
   - 演練用備份目錄 `B`
   - MariaDB、PHP、Nginx、Certbot 版本
   - 自己的連線來源 IP（可遮住最後一段）
2. 版本對照：查到的版本和固定標籤是否相同。不同時寫改了哪一行，以及為什麼沒有把資料庫改得更舊。
3. 災難演練：寫明刪除前兩道檢查都過了，才執行 `down -v`。還原後寫文章標題、圖片是否還在、靜態網站是否還在。
4. SSH：寫目前是金鑰可登入、密碼被拒絕，或寫明停在 STEP 9，本週沒關密碼。沒有先用新視窗確認金鑰登入，就不可以關密碼登入。
5. fail2ban：`ignoreip` 放了哪個 IP，以及為什麼要放。全班同一條外線時，沒放這格就可能整班被封。
6. 防火牆觀察表三列都要填，再用三到五句話回答：ufw 只放行 22 時，為什麼 Docker 上的網站還連得到，真正的防線在哪裡。學生的 VM 本週不要啟用 ufw。
7. 課後：自己電腦上 `SHA256SUMS` 五行 `OK` 的畫面，以及 `crontab -l`。隔天再補 `backup.log` 裡的「完成：」。時區是 `UTC` 就寫 `30 18 * * *`；是 `Asia/Taipei` 就寫 `30 2 * * *`。

## 不要收

備份檔（`.sql`、`.tar.gz`）、`.env`、憑證私鑰、整包 `~/backups`。這些裡面有資料庫密碼。

繳交檔只留：改過的 `compose.yml`、`10-hardening.conf`、`jail.local`（`ignoreip` 可遮）、報告。

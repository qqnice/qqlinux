企業級日誌中心建置指南

探討 Log Server 的重要性，解析為何選擇 Graylog，並提供在 Ubuntu 24.04 上的完整實戰安裝步驟。

為什麼企業需要 Log Server？

在分散式系統與微服務架構下，集中管理日誌是維持系統穩定與安全的基石。

集中化故障排除

當系統發生錯誤時，工程師不需要逐一登入數十台伺服器查看 Log。透過集中式 Log Server，只需輸入關鍵字與時間範圍，即可瞬間定位問題根源，大幅縮短 MTTR (平均修復時間)。

資安稽核與威脅偵測

日誌是記錄駭客足跡的重要證據。集中收集防火牆、作業系統與應用的登入日誌，配合告警機制，能在遭受暴力破解或異常存取時第一時間反應，並符合資安法規稽核要求。

資料視覺化與趨勢分析

Log 不再只是密密麻麻的文字。現代 Log Server 能將非結構化資料萃取成結構化欄位，繪製成直觀的儀表板 (Dashboard)，幫助維運人員即時掌握系統健康度與流量趨勢。

防止資料竄改或遺失

如果攻擊者入侵了某台應用伺服器，他們通常會刪除本機 Log 來毀滅證據。將 Log 即時傳送到獨立且權限受控的 Log Server，可確保日誌資料的不可否認性與完整性。

為何選擇 Graylog？

在眾多日誌解決方案 (如 ELK/EFK, Splunk) 中，Graylog 脫穎而出的核心優勢。

強悍且易用的

開源日誌管理平台

  • 1

    極致友善的 Web UI 與查詢語法

    相較於 Kibana 需要學習 KQL 或 Lucene，Graylog 的搜尋介面更加直覺。它提供簡單且強大的過濾條件，並內建極佳的告警設定介面，學習曲線極低。

  • 2

    強大的 Pipelines (管線) 資料處理

    不需要像 Logstash 那樣編寫複雜的設定檔，Graylog 內建 Pipelines 與 Extractors 功能，可以直接在網頁介面上靈活地拆解、過濾、轉換 Log 內容（如解析 Nginx/Apache 日誌）。

  • 3

    內建權限管理與告警機制

    開源版 (Open) 即具備了 Role-Based Access Control (RBAC) 權限控制以及強大的 Alerts 告警功能（可串接 Email, Slack 等），這在許多競品中通常需要付費才能使用。

  • 4

    基於 OpenSearch，效能卓越

    底層採用 OpenSearch (Elasticsearch 的開源分支) 作為資料儲存引擎，能夠應付海量資料的寫入與毫秒級的搜尋查詢。

Ubuntu 24.04 實戰安裝步驟

從基礎套件到系統上線的完整流程。

您的環境設定與網路建議

  • 作業系統： Ubuntu 24.04
  • 時區： 台灣 (Asia/Taipei)
  • 防火牆： 不設定 (Port 9000 互通即開放)
  • 主機 IP： 10.24.1.101 (DHCP配發)
💡 網路設定強烈建議：
因為您的主機使用 DHCP (目前為 10.24.1.101)，強烈建議在設定 Graylog 時將監聽位址綁定為 0.0.0.0:9000（監聽所有網路介面）。如果強行綁定 10.24.1.101:9000，未來若 DHCP 配發了新的 IP，Graylog 服務將會因為找不到該 IP 而 Crash 無法啟動。

Step 1系統基礎設定

設定時區為台灣 (Asia/Taipei) 並更新系統、安裝必要工具。

Bash 
sudo timedatectl set-timezone Asia/Taipei
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl wget gnupg2 uuid-runtime pwgen apt-transport-https dirmngr

Step 2安裝 MongoDB 7.0

Graylog 需要 MongoDB 來儲存系統設定與使用者資訊。(註：Ubuntu 24.04 使用 22.04 jammy 的庫可完美相容)。

1. 加入官方金鑰與軟體源 
curl -fsSL https://www.mongodb.org/static/pgp/server-7.0.asc | sudo gpg -o /usr/share/keyrings/mongodb-server-7.0.gpg --dearmor
echo "deb [ arch=amd64,arm64 signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list
2. 安裝並啟動服務 
sudo apt update
sudo apt install -y mongodb-org
sudo systemctl daemon-reload
sudo systemctl enable --now mongod
# 檢查狀態以確認是否執行中
# systemctl status mongod

Step 3安裝 OpenSearch 2.x

Graylog 6.0 官方建議使用 OpenSearch 來作為日誌儲存引擎。安裝時使用隨機密碼，隨後我們會關閉認證，由 Graylog 統一負責安全。

1. 加入金鑰、軟體源與安裝 
curl -o- https://artifacts.opensearch.org/publickeys/opensearch.pgp | sudo gpg --dearmor --batch --yes -o /usr/share/keyrings/opensearch-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/opensearch-keyring.gpg] https://artifacts.opensearch.org/releases/bundle/opensearch/2.x/apt stable main" | sudo tee /etc/apt/sources.list.d/opensearch-2.x.list

sudo apt update
sudo env OPENSEARCH_INITIAL_ADMIN_PASSWORD=$(pwgen -s 32 1) apt install -y opensearch

2. 編輯 OpenSearch 設定檔 (sudo nano /etc/opensearch/opensearch.yml)，將內容替換為以下：

opensearch.yml 
cluster.name: graylog
node.name: ${HOSTNAME}
path.data: /var/lib/opensearch
path.logs: /var/log/opensearch
discovery.type: single-node
network.host: 127.0.0.1
action.auto_create_index: false
plugins.security.disabled: true
3. 啟動並設定開機自動執行 
sudo systemctl daemon-reload
sudo systemctl enable --now opensearch

Step 4 & 5安裝與設定 Graylog 6.0

1. 安裝 Graylog 
wget https://packages.graylog2.org/repo/packages/graylog-6.0-repository_latest.deb
sudo dpkg -i graylog-6.0-repository_latest.deb
sudo apt update
sudo apt install -y graylog-server

2. 產生密碼與雜湊值。首先，產生一組 96 碼的 password_secret：

Bash (產生 password_secret) 
pwgen -N 1 -s 96

接著，產生 admin 密碼的 SHA-256 雜湊值 (此處以密碼 "admin" 為例，請複製印出的雜湊值)：

Bash (產生密碼雜湊) 
echo -n "admin" | shasum -a 256 | cut -d" " -f1
# 結果應為: 8c6976e5b5410415bde908bd4dee15dfb167a9c873fc4bb8a81f6f2ab448a918

3. 編輯 Graylog 設定檔 (sudo nano /etc/graylog/server/server.conf)，修改以下參數：

server.conf 關鍵修改 
# 1. 貼上您剛剛用 pwgen 產生的 96 碼字串
password_secret = <這裡貼上_password_secret>

# 2. 貼上您剛剛產生的密碼 Hash 值 (admin)
root_password_sha2 = 8c6976e5b5410415bde908bd4dee15dfb167a9c873fc4bb8a81f6f2ab448a918

# 3. 設定時區為台北
root_timezone = Asia/Taipei

# 4. 綁定所有介面 (解決 DHCP IP 變動問題)
http_bind_address = 0.0.0.0:9000

Step 6啟動並登入 Web 介面

啟動服務與監看日誌 
sudo systemctl daemon-reload
sudo systemctl enable --now graylog-server
# 監看日誌直到看見 Graylog server up and running.
sudo tail -f /var/log/graylog-server/server.log

服務已上線，您可以登入了！

打開瀏覽器並輸入以下網址（由於您不設定防火牆，只要網段互通即可直接連線）：

  • 網址： http://10.24.1.101:9000
  • 帳號： admin
  • 密碼： admin (或您自訂的密碼)
